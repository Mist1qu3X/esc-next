Results & Rankings
как заполнять в Strapi

Раздел сайта Results & Rankings собирается из 5 коллекций Strapi. Ниже — что откуда берётся, какие поля заполнять, с примерами реальных значений с прода и мокапами форм. Всё работает через Content Manager в админке Strapi.

● Структура корректна каждая часть страницы = одна коллекция, дублей нет

Единственное, за чем реально нужно следить при ручном вводе — строки дисциплин и категории: сайт сопоставляет строки буквально. Опечатка в поле discipline = строка просто не покажется. Поэтому ниже даны точные списки допустимых значений — сверяйтесь с ними.

Records-PDF читаются из той же коллекции Document, что и раздел Documents. Заводите PDF рекордов один раз в Documents — кнопка на странице Results подхватится сама. Дублировать не нужно.

Официальный PDF рейтинга (кнопка «OFFICIAL PDF»)

Кнопка на детали рейтинга берёт файл из коллекции Document с theme = Ranking. Сайт находит нужный PDF по названию дисциплины и полу в полях title / description. Именуйте по образцу:

titledescription→ где появится
European Ranking — 10m Air Pistol Men10m Air Pistol · Menкнопка PDF в 10m Air Pistol · Men
European Ranking — Trap WomenTrap · Womenкнопка PDF в Trap · Women
!
Главное — чтобы в title/description была точная строка дисциплины (из списка 7) и слово Men либо Women. Чтобы обновить PDF — просто замените файл в этом доке (или создайте новый с таким же названием). Никакого кода трогать не нужно — раньше эти ссылки были прошиты в коде, теперь всё через Documents.
04

Results — Event + Result Detail + PDF

Вкладка RESULTS — это список соревнований, у каждого своя таблица результатов и/или PDF. Три источника:

A. Соревнование — коллекция «Event»

Карточка в списке результатов = запись Event. Ключевые поля, чтобы событие попало в Results:

ПолеЗначениеЗачем
statusEventFINISHEDЗавершённые → в Results; UPCOMING → в Calendar
hasResultstrueУ события есть таблицы результатов
hasResultBooktrueПоказать кнопку result-book PDF
categorySENIOR / JUNIORТег на карточке
disciplinesсписок дисциплинКакие карточки дисциплин показать
location, date, endDate—Обязательные поля карточки

B. Таблицы результатов — «Result Detail»

i
Строки Result Detail обычно заводятся автоматически импортёром SIUS, не вручную (поля shots / shotDetail — служебные JSON). Вручную это трудоёмко: одна запись = один спортсмен в одной дисциплине. Если всё же нужно вручную — заполните eventSlug (точно = slug события), position, athleteName, federationCode, total, discipline (ЗАГЛАВНЫМИ, напр. 10M AIR RIFLE) и category (ALL/MEN/WOMEN).

05

Общие правила — читать всем

  1. Всегда жмите «Publish». Черновик (Draft) на сайте не виден. После сохранения (Save) запись ещё в черновике — нужен зелёный Publish.
  2. Строки дисциплин и категорий — буквально. Регистр и пробелы важны. Не уверены — откройте существующую запись той же дисциплины и скопируйте строку.
  3. Флаги — автоматические. Достаточно кода страны (federationCode / country). Поле flag — запасной ручной вариант, трогать только если флаг не подгрузился.
  4. Дата — формат ГГГГ-ММ-ДД (напр. 2026-07-27).
  5. Records-PDF заводятся в Documents (theme = Records) — и там же появляются кнопки на Results. Отдельно дублировать не нужно.
  6. Изменения после Publish появляются на сайте в течение ~3 минут (кэш). Если не видно сразу — подождите и обновите страницу.
